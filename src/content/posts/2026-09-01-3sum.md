**Pattern:** Sort, fix one value, then use two pointers.

**Simple idea:** Fix the first value. The remaining problem is Two Sum on a sorted range. If
the sum is too small, move the left pointer. If it is too large, move the right pointer.

```python
def three_sum(nums: list[int]) -> list[list[int]]:
   nums.sort()
   answer: list[list[int]] = []

   for index, first in enumerate(nums):
      if index > 0 and first == nums[index - 1]:
         continue

      left, right = index + 1, len(nums) - 1
      while left < right:
         total = first + nums[left] + nums[right]
         if total < 0:
            left += 1
         elif total > 0:
            right -= 1
         else:
            answer.append([first, nums[left], nums[right]])
            left += 1
            right -= 1
            while left < right and nums[left] == nums[left - 1]:
               left += 1

   return answer
```

**Cost:** $O(n^2)$ time and $O(1)$ extra space, not counting sorting and the answer.
