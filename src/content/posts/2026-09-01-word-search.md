Mark a cell only while its candidate path is active, then restore it so other paths can use it.

## Problem

Find `ABCCED` in the board `ABCE / SFCS / ADEE` using up, down, left or right moves.
A candidate cannot reuse a coordinate; different candidates may reuse it.
The reference expects independent mutable rows, a rectangular board and single-character cells, with `#` excluded from board and word.
An empty word succeeds even on an empty board.

## Picture

At `search(row, col, index)`, marked ancestors spell `word[:index]`.
The candidate must be in bounds, unused and equal to the next character.
Save its character, mark it, then try down, up, right and left.

The trace follows `(0,0),(0,1),(0,2),(1,2),(2,2),(2,1)`.
At `E`, down is outside, up is already marked and right contains the wrong character.
Left reaches `D` and completes the word.
Completion is checked before reading another cell; no additional valid neighbor is required.

The Boolean result short-circuits remaining directions, but each accepted call still restores its own cell.
Restoration unwinds `D,E,C,C,B,A`.
Path ownership is temporary, unlike the permanent component marking used for island counting.

## Code

```python
def word_search(board: list[list[str]], word: str) -> bool:
   if not word:
      return True
   if not board or not board[0]:
      return False

   def search(row: int, col: int, index: int) -> bool:
      if index == len(word):
         return True
      if not (0 <= row < len(board) and 0 <= col < len(board[0])):
         return False
      if board[row][col] != word[index]:
         return False

      char = board[row][col]
      board[row][col] = "#"
      found = (
         search(row + 1, col, index + 1)
         or search(row - 1, col, index + 1)
         or search(row, col + 1, index + 1)
         or search(row, col - 1, index + 1)
      )
      board[row][col] = char
      return found

   return any(
      search(row, col, 0)
      for row in range(len(board))
      for col in range(len(board[0]))
   )
```

For word length $L$, a loose upper bound is $O(RC4^L)$ time and $O(L)$ path stack space.
The search is exponential, not linear merely because each current path avoids repeats.
Long words can exceed Python's recursion limit.
Normal returns restore the board; an exception can leave this in-place reference marked.

### Failure Check

On board `AB`, `ABA` must fail because the first `A` cannot be reused.
A permanent visited set also incorrectly blocks coordinates needed by later candidates.
Returning immediately on success before restoring would change the caller's board.

## Change to an Arbitrary Alphabet

**New task:** Allow `#` in the board or query.

**Picture and change:** Track used coordinates in a path-local set instead of overwriting characters.
The `finally` block releases ownership even when a recursive call raises.

```python
def word_search_set(board, word):
   if not word:
      return True
   if not board or not board[0]:
      return False
   used = set()
   def search(row, col, index):
      if index == len(word):
         return True
      if not (0 <= row < len(board) and 0 <= col < len(board[0])) or (row, col) in used or board[row][col] != word[index]:
         return False
      used.add((row, col))
      try:
         return any(search(row + row_step, col + col_step, index + 1) for row_step, col_step in ((1,0),(-1,0),(0,1),(0,-1)))
      finally:
         used.remove((row, col))
   return any(search(row, col, 0) for row in range(len(board)) for col in range(len(board[0])))
```

**Check:** Board `[["A","B"]]` and `"AB#"` return `False`; board `[["#","A"]]` and `"#A"` return `True`.
The first case fools the sentinel reference into accepting a previously used cell as a literal `#`.
This version never modifies the board.

**Use when:** No character can be reserved as a marker.

## Change to Counting Coordinate Paths

**New task:** Count every matching simple coordinate path, including opposite traversal orders.

**Picture and change:** Sum branches instead of stopping at one, and emit one count at the final matched cell.

```python
def count_word_paths(board, word):
   if not word:
      return 1
   if not board or not board[0]:
      return 0
   used = set()
   def search(row, col, index):
      if not (0 <= row < len(board) and 0 <= col < len(board[0])) or (row, col) in used or board[row][col] != word[index]:
         return 0
      if index == len(word) - 1:
         return 1
      used.add((row, col))
      total = sum(search(row + row_step, col + col_step, index + 1) for row_step, col_step in ((1,0),(-1,0),(0,1),(0,-1)))
      used.remove((row, col))
      return total
   return sum(search(row, col, 0) for row in range(len(board)) for col in range(len(board[0])))
```

**Check:** A two-by-two board of `A` has eight directed paths spelling `AA`: four starts, each with two neighbors.
The empty word contributes one empty path, including on an empty board.
Counting retains exponential worst-case search and $O(L)$ current-path storage, not storage for all returned witnesses.

**Use when:** Distinct coordinate paths, rather than distinct strings, define the output.

### Transfer Check

Why not sum the original four recursive calls after reaching the final character?

### Answer

All four would report the same completed path, multiplying its contribution by four.
Emit once at the final matched cell instead.
