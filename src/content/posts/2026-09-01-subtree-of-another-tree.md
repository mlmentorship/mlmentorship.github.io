Determine whether one complete binary tree occurs as a rooted subtree inside another tree.

## Problem

**Input.** A main binary tree and a pattern binary tree, both finite and without cycles or shared children.

**Output.** Return `True` if some main-tree node roots a subtree exactly equal to the pattern; otherwise return `False`.

**Rules.** Matching requires equal values and identical left/right structure, including all missing children.
You cannot ignore extra descendants below a chosen root. Preserve both trees.
An empty pattern matches anywhere, including an empty main tree; a nonempty pattern cannot match an empty main tree.

**Example.** A node 4 with leaf children 1 and 2 matches a pattern with exactly that structure.
If the pattern's node 2 is a leaf but the main node 2 has an extra child, that candidate fails.

## Picture

Compare main root three with pattern root four. That candidate fails immediately; try the main tree's left child next.

| Candidate or pair | Required evidence |
| --- | --- |
| Main 3 versus pattern 4 | Different values: reject this candidate |
| Main 4 versus pattern 4 | Equal roots: compare both child pairs |
| Main 1 versus pattern 1 | Equal values and both null pairs |
| Main 2 versus pattern 2 | Equal values and both null pairs |
| Completed candidate at path `L` | Return `True`; skip main node 5 |

## Code

Use this node type for a local run.

```python
from dataclasses import dataclass


@dataclass
class TreeNode:
   val: int
   left: "TreeNode | None" = None
   right: "TreeNode | None" = None
```

```python
def is_subtree(root: TreeNode | None, subroot: TreeNode | None) -> bool:
   def same(first: TreeNode | None, second: TreeNode | None) -> bool:
      if first is None or second is None:
         return first is second
      return (
         first.val == second.val
         and same(first.left, second.left)
         and same(first.right, second.right)
      )

   if subroot is None:
      return True
   if root is None:
      return False
   return (
      same(root, subroot)
      or is_subtree(root.left, subroot)
      or is_subtree(root.right, subroot)
   )
```

### Separate Locate from Verify

The outer OR tries the current root, then left, then right. Its first success stops further candidate search.

The inner AND requires equal values and exact equality of both aligned child pairs. One missing child matches only another missing child.

An extra descendant under candidate node two breaks the match, even when all pattern values remain visible.

### Count Repeated Verification

For nonempty trees of sizes $n$ and $m$, worst-case time is $O(nm)$.

Many candidate roots can repeat almost the same long comparison before failing. One outer traversal does not imply linear total work.

Active recursion is bounded by the main-tree height plus base-case frames: $O(h)$ stack space. Deep trees can exceed Python's recursion limit.

The platform supplies `TreeNode` with `val`, `left`, and `right`; this snippet assumes that definition.

**Recall:** What does equal root value prove? Only that this candidate deserves child comparisons, not that the rooted trees match.

## Return Every Exact Candidate Path

**Choose this when:** A Boolean answer does not provide enough location evidence.

Paths use `L` and `R`; the empty string identifies the main root. Traverse left before right and retain exact null semantics.

```python
def subtree_paths(root, subroot):
   def equal(first, second):
      if first is None or second is None:
         return first is second
      return (
         first.val == second.val
         and equal(first.left, second.left)
         and equal(first.right, second.right)
      )

   if subroot is None:
      return []
   answer = []
   stack = [] if root is None else [(root, "")]
   while stack:
      node, path = stack.pop()
      if equal(node, subroot):
         answer.append(path)
      if node.right is not None:
         stack.append((node.right, path + "R"))
      if node.left is not None:
         stack.append((node.left, path + "L"))
   return answer
```

This interface locates nonempty patterns only; an empty pattern returns no candidate paths.

The pictured result is `["L"]`. Two equal-valued leaves in different branches produce distinct paths.

Verification can still take $O(nm)$ time. Path copies can add $O(nh)$ time.

Pending strings can need $O(h^2)$ working characters, plus returned paths. The recursive verifier retains its depth limit.

## Permit Omitted Pattern Descendants

**Choose this when:** Missing pattern children explicitly mean "no restriction."

```python
def contains_partial_tree(root, pattern):
   def matches(node, wanted):
      if wanted is None:
         return True
      if node is None:
         return False
      return (
         node.val == wanted.val
         and matches(node.left, wanted.left)
         and matches(node.right, wanted.right)
      )

   if pattern is None:
      return True
   if root is None:
      return False
   return (
      matches(root, pattern)
      or contains_partial_tree(root.left, pattern)
      or contains_partial_tree(root.right, pattern)
   )
```

Pattern root one with left child two matches main root one with children two and three. Exact equality rejects that candidate.

A required right child four still fails against right child three. Extra descendants are allowed; wrong required values are not.

Worst-case time remains $O(nm)$ and recursive space $O(h)$. This is partial matching, not exact subtree equality.
