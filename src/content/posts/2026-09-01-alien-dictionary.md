Infer a possible alphabet from words already sorted under an unknown character order.

## Problem

**Input.** A list of words sorted lexicographically under an unknown alphabet.

**Output.** Return a string containing every observed character exactly once in a compatible alphabet order.

**Rules.** At the first unequal character, the earlier word's character must come earlier in the alphabet.
A word precedes any longer word that has it as a prefix.
Return any compatible order if several exist, or `""` if no order exists.
An empty word list also returns `""`. Leave the words unchanged.

**Example.** `["wrt", "wrf", "er", "ett", "rftt"]` permits `"wertf"`.
`["abc", "ab"]` returns `""`: a longer word cannot precede its own prefix.

## Picture

Lexicographic comparison stops at the first difference.
Record that one necessary directed edge; ignore later positions.
If no difference exists, the longer word cannot precede its exact prefix.
Include every observed character, even without incident edges, and deduplicate edges before incrementing indegrees.

| Adjacent words | Forced edge |
| --- | --- |
| `wrt`, `wrf` | `t -> f` |
| `wrf`, `er` | `w -> e` |
| `er`, `ett` | `r -> t` |
| `ett`, `rftt` | `e -> r` |

These rules form `w -> e -> r -> t -> f`.
Emit zero-indegree characters, remove their outgoing obligations, and enqueue each newly unblocked character.
Only `w` starts ready; the resulting order is `wertf`.
Emitting fewer characters than exist proves a cycle prevents completion.

## Code

```python
from collections import deque

def _first_difference(first: str, second: str) -> tuple[str, str] | None:
   for first_char, second_char in zip(first, second, strict=False):
      if first_char != second_char:
         return first_char, second_char
   return None


def alien_order(words: list[str]) -> str:
   graph = {char: set() for word in words for char in word}
   indegree = {char: 0 for char in graph}

   for first, second in zip(words, words[1:], strict=False):
      difference = _first_difference(first, second)
      if difference is None:
         if len(first) > len(second):
            return ""
         continue

      first_char, second_char = difference
      if second_char not in graph[first_char]:
         graph[first_char].add(second_char)
         indegree[second_char] += 1

   ready = deque(char for char, count in indegree.items() if count == 0)
   order: list[str] = []

   while ready:
      char = ready.popleft()
      order.append(char)
      for next_char in graph[char]:
         indegree[next_char] -= 1
         if indegree[next_char] == 0:
            ready.append(next_char)

   return "".join(order) if len(order) == len(indegree) else ""
```

The source returns any consistent extension, not necessarily the lexically smallest or uniquely implied alphabet.
Empty output also represents no observed characters; it does not distinguish that valid empty case from failure.
For $C$ input characters, $V$ distinct characters and $E$ distinct edges, expected work is $O(C+V+E)$.
Additional graph storage is $O(V+E)$.

## Change to an Order and Uniqueness Report

**New task:** Report validity and ambiguity while selecting the lexical minimum consistent alphabet.

**Picture and change:** Use a min-heap for ready characters and flag ambiguity whenever more than one choice is available.

```python
import heapq

def alien_order_report(words):
   graph = {char: set() for word in words for char in word}
   indegree = dict.fromkeys(graph, 0)
   for first, second in zip(words, words[1:]):
      difference = _first_difference(first, second)
      if difference is None:
         if len(first) > len(second):
            return {"order": "", "valid": False, "unique": False}
      else:
         before, after = difference
         if after not in graph[before]:
            graph[before].add(after)
            indegree[after] += 1
   ready = [char for char in graph if indegree[char] == 0]
   heapq.heapify(ready)
   order, unique = [], True
   while ready:
      unique = unique and len(ready) == 1
      char = heapq.heappop(ready)
      order.append(char)
      for following in graph[char]:
         indegree[following] -= 1
         if indegree[following] == 0:
            heapq.heappush(ready, following)
   valid = len(order) == len(graph)
   return {"order": "".join(order) if valid else "", "valid": valid, "unique": unique and valid}
```

**Check:** `["ab","ac"]` gives `{"order":"abc","valid":True,"unique":False}`.
The letter `a` is unconstrained; choosing it first is policy, not evidence of its original rank.
The invalid prefix example reports both flags false.
Heap processing adds $O(V\log(V+1))$ work; uniqueness concerns only the observed character set.

**Use when:** Determinism and underdetermination must both be explicit.

## Change to Candidate Validation

**New task:** Check whether a supplied alphabet explains the observed word ordering.

**Picture and change:** Rank supplied characters, reject duplicates or missing observed symbols, then check adjacent-word first differences.

```python
def consistent_alphabet(words, order):
   rank = {char: index for index, char in enumerate(order)}
   if len(rank) != len(order) or any(char not in rank for word in words for char in word):
      return False
   for first, second in zip(words, words[1:]):
      difference = _first_difference(first, second)
      if difference is None:
         if len(first) > len(second):
            return False
      elif rank[difference[0]] >= rank[difference[1]]:
         return False
   return True
```

**Check:** `["ab","ac"]` accepts `"abc"` and rejects `"cba"`.
Extra unobserved characters are allowed; duplicated characters are not.
Consistency does not establish uniqueness or historical truth.
Both variations reuse the complete `_first_difference` helper above.

**Use when:** Another authority supplies the alphabet.

### Transfer Check

Why are adjacent pairs sufficient?

### Answer

A sequence is sorted exactly when every adjacent pair is nondecreasing under the same total order.
Transitivity handles farther pairs.
