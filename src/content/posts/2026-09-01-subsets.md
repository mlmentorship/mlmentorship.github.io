**Pattern:** Backtracking with a start position.

**Simple idea:** Every partial path is already one valid subset. Save it. Then add each value
that comes after the last chosen position.

```python
def subsets(nums: list[int]) -> list[list[int]]:
   answer: list[list[int]] = []
   path: list[int] = []

   def choose(start: int) -> None:
      answer.append(path.copy())
      for index in range(start, len(nums)):
         path.append(nums[index])
         choose(index + 1)
         path.pop()

   choose(0)
   return answer
```

**Cost:** $O(n2^n)$ time and $O(n)$ working space, not counting the answer.
