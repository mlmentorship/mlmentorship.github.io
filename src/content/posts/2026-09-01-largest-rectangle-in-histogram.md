Find the greatest rectangular area that fits entirely beneath a row of histogram bars.

## Problem

**Input.** A list `heights` of nonnegative integer bar heights, with adjacent bars each having width one.

**Output.** Return the largest area of an axis-aligned rectangle fully contained under the histogram.

**Rules.** A rectangle spans consecutive bars; its height cannot exceed the shortest included bar.
The bars have no horizontal gaps. Equal heights and zero-height bars are allowed.
Do not modify the list. Empty input returns zero.

**Example.** `[2, 1, 5, 6, 2, 3]` returns `10`.
The bars at indices 2 and 3 support a rectangle of width 2 and height 5.

## Picture

In `[2,1,5,6,2,3]`, reaching height `2` closes height `6` at width one, then height `5` at width two.
The latter area is `10`.
The new height inherits the earliest popped start.

Stack heights are nondecreasing, not strictly increasing: the literal `>` comparison retains equal heights.
Each saved start extends left across already-cleared taller bars.
The first shorter right bar prevents further extension at that height.
An appended zero finalizes every positive-height candidate.

## Code

```python
def largest_rectangle_area(heights: list[int]) -> int:
   stack: list[tuple[int, int]] = []
   best = 0

   for index, height in enumerate(heights + [0]):
      start = index
      while stack and stack[-1][1] > height:
         start, old_height = stack.pop()
         best = max(best, old_height * (index - start))
      stack.append((start, height))

   return best
```

**Cost:** $O(n)$ time and $O(n)$ space.

Each candidate is pushed and popped at most once; `heights + [0]` also copies $O(n)$ references.
Bounds count scalar operations, not integer bit costs.

## Change the Requirement

### Return a Rectangle Witness

**New task:** Return `(area, left, right_exclusive, height)`.

**Picture and change:** Save each strictly better popped rectangle, not only its area.

**Code:** This complete variant uses a virtual sentinel without copying the input.

```python
def largest_rectangle_witness(heights: list[int]):
   stack = []
   best = (0, 0, 0, 0)
   for index in range(len(heights) + 1):
      height = heights[index] if index < len(heights) else 0
      start = index
      while stack and stack[-1][1] > height:
         start, old_height = stack.pop()
         area = old_height * (index - start)
         if area > best[0]:
            best = (area, start, index, old_height)
      stack.append((start, height))
   return best
```

**Check:** `[2,1,2]` returns `(3,0,3,1)`; equal-area ties retain the first strict improvement.

**Use when:** A caller needs boundaries; time and workspace stay linear.

### Give Bars Unequal Widths

**New task:** Accept a positive integer width per bar.

**Picture and change:** Carry physical left coordinates; replace index differences with coordinate differences.

**Code:** Heights retain the nonnegative-integer contract.

```python
def largest_weighted_rectangle(heights: list[int], widths: list[int]) -> int:
   if len(heights) != len(widths) or any(width <= 0 for width in widths):
      raise ValueError("each bar needs one positive width")
   stack, best, position = [], 0, 0
   for index in range(len(heights) + 1):
      height = heights[index] if index < len(heights) else 0
      start = position
      while stack and stack[-1][1] > height:
         start, old_height = stack.pop()
         best = max(best, old_height * (position - start))
      stack.append((start, height))
      if index < len(heights):
         position += widths[index]
   return best
```

**Check:** Heights `[2,1,2]` and widths `[2,1,2]` yield `5`, not the unit-width answer `3`.

**Use when:** Bars occupy unequal horizontal spans.
The same push/pop argument gives linear time and workspace.
