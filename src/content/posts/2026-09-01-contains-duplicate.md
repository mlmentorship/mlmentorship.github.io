**Pattern:** Set.

**Simple idea:** A set removes repeated values. A duplicate exists when the set is shorter
than the input.

```python
def contains_duplicate(nums: list[int]) -> bool:
   return len(nums) != len(set(nums))
```

**Cost:** $O(n)$ average time and $O(n)$ space.
