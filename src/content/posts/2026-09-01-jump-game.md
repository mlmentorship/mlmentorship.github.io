**Pattern:** Greedy farthest reach.

**Simple idea:** Keep the farthest position reachable from everything processed. If the
current position is past that point, it cannot be reached.

```python
def can_jump(nums: list[int]) -> bool:
   farthest = 0

   for index, jump in enumerate(nums):
      if index > farthest:
         return False
      farthest = max(farthest, index + jump)
   return True
```

**Cost:** $O(n)$ time and $O(1)$ space.
