Determine whether two binary trees have identical shapes and equal values in every corresponding position.

## Problem

**Input.** Two roots, `first` and `second`, of finite binary trees without cycles or shared children.

**Output.** Return `True` exactly when all corresponding node values and child positions match.

**Rules.** Compare structure as well as values; a left child does not match a right child.
Values use Python `==`. Nodes need not have the same object identities.
Preserve both trees. Two empty trees match; exactly one empty tree does not.

**Example.** Root 1 with children 2 and 3 does not match root 1 with only left child 2.
Their compact level-order notations are `[1, 2, 3]` and `[1, 2, null]`; return `False`.

## Picture

Place the two roots together, then compare their corresponding child positions.
Roots `1/1` pass; left children `2/2` and their missing children pass.
Right pair `3/None` fails, so the complete comparison fails.

Each call answers one exact question: do the complete subtrees at these aligned roots match?

Handle missing nodes before reading values or child fields.
Both missing succeeds; exactly one missing fails.
For real nodes, require value equality **and** both child comparisons.

## Code

```python
def same_tree(first: TreeNode | None, second: TreeNode | None) -> bool:
   if first is None or second is None:
      return first is second
   return (
      first.val == second.val
      and same_tree(first.left, second.left)
      and same_tree(first.right, second.right)
   )
```

The `and` chain stops at its first failure: values, then left pair, then right pair.
Worst-case time is $O(n)$ in total input nodes, with $O(h)$ stack space along compared paths.
A mismatch can stop earlier; a deep chain can exceed Python's recursion limit.

### Failure Check

`[1,2]` and `[1,null,2]` have the same preorder values but different child positions.
Separate allocations can still match; real-node identity is not required.
Both empty trees match; only one empty tree does not.
This recursion is not cyclic-graph equivalence.

## Change the Alignment

**New task:** Check whether one tree is the mirror of the other.

**Picture and change:** Cross left/right pairings, while retaining every value and missing-node check.

```python
def mirror_equal(first, second):
   if first is None or second is None:
      return first is second
   return (
      first.val == second.val
      and mirror_equal(first.left, second.right)
      and mirror_equal(first.right, second.left)
   )
```

**Check:** `[1,2,3]` and `[1,3,2]` pass mirror equality but fail ordinary equality.
Neither input is mutated.

**Use when:** Correspondence is reflected, not position-for-position.
This compares the mirror relation; it does not [invert a tree](/questions/invert-binary-tree/).

## Change the Compared Fields

**New task:** Compare shape only.

**Picture and change:** Remove value equality, but retain aligned child positions and missing-node cases.

```python
def same_shape(first, second):
   if first is None or second is None:
      return first is second
   return same_shape(first.left, second.left) and same_shape(first.right, second.right)
```

**Check:** `[1,2]` and `[9,8]` pass.
`[1,2]` and `[1,null,2]` still fail.
Both variants retain the original worst-case time, stack and recursion-limit qualifications.

**Use when:** The specification declares value labels irrelevant.

### Transfer Check

Why is `first is second` correct in the original missing-node branch?

### Answer

At least one argument is `None` there.
Identity succeeds only when both are `None`; it imposes no identity requirement on real nodes.
